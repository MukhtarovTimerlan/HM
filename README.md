Для обработки 40 000 строк данных (часть от 3 млн) применена гибридная стратегия chunking, которая обеспечивает оптимальный баланс между сохранением смыслового контекста и эффективностью векторного поиска. В результате обработки получено 54 000 чанков.  

Исходный текст поста (средняя длина ~800 символов)             
1. Предобработка текста:  
     - Удаление лишних пробелов и переносов           
     - Нормализация кодировки                          
     - Проверка на пустоту  


  2. Оценка длины текста:                              
     - Длина < 500 символов → один чанк                
     - Длина ≥ 500 символов → рекурсивное разбиение     
     
  
  3. Интеллектуальное разбиение:                       
     - Поиск границ по пробелам/знакам препинания      
     - Сохранение целостности предложений              
     - Создание перекрытия в 50 символов               
 

Каждый чанк содержит полный набор метаданных исходного поста:  
```code
{  
    "chunk_id": 12345,  
    "post_id": "original_post_789",  
    "channel_name": "Название_канала",  
    "post_date": "2025-03-15",  
    "chunk_index": 2,  
    "total_chunks": 3,  
    "views": 1500,  
    "reactions": 45,  
    "comments": 12,  
    "text_preview": "Пример текста чанка...",  
    "is_boundary": true  
}  
```

Обоснование выбранных параметров  

1. Размер чанка: 500 символов
  - Модельные ограничения: Большинство эмбединг-моделей работают оптимально с текстом 256-512 токенов

  - Контекстная полнота: Позволяет сохранить законченную мысль или аргумент

- Эффективность поиска: Достаточная длина для релевантного поиска, но не избыточная

2. Перекрытие: 50 символов (10%)
- Минимальное дублирование: Увеличивает объем данных лишь на ~10%

- Контекстная непрерывность: Гарантирует, что важная информация на границе чанков не будет потеряна

- Эффективность хранения: Не создает избыточной нагрузки на векторную БД


Распределение длин: Большинство постов требуют 1-2 чанков, длинные - 3-4

Эффективность обработки: Оптимальный баланс между детализацией и производительностью
